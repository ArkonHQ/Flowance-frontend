## 📖 Overview

Flowance simplifies freelance workflow management by combining:

- Client management  
- Project tracking  
- Task organisation  
- Financial analytics  
- Invoice monitoring  
- Productivity insights  

This repository contains the frontend application and user interface layer.

## ⚡ Features

### Authentication
- Secure authentication flow  
- Protected routes  
- Session handling  
- Token‑based API communication  

---

### Dashboard
- Monthly revenue analytics  
- Revenue comparison  
- Productivity insights  
- Project statistics  
- Financial overview  

---

### Clients
- Create and manage clients  
- View client history  
- Track client‑related projects  

---

### Projects
- Full lifecycle status management  
  `Todo` → `In Progress` → `Hold` → `Completed` → `Cancelled`  
- Deadline tracking  
- Progress monitoring  

---

### Tasks
- Task management system  
- Progress tracking  
- Deadline organisation  
- Project‑based task grouping  

---

### Invoices & Payments
- Invoice tracking  
- Paid / unpaid status  
- Revenue monitoring  
- Financial summaries  

---

### Notifications
- Upcoming deadlines  
- Overdue projects  
- Payment reminders

## 🎨 UI Philosophy

Flowance is built for **focus** — no clutter, just speed and clarity.

- **Linear** – precision and command bar  
- **Notion** – flexible workflows  
- **Raycast** – instant actions  

The result: a professional dashboard experience that gets out of your way.
